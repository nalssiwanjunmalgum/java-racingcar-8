## 기능 요구 사항

- [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
  - 주어진 횟수, n대의 자동차, 자동차
    - [x] 자동차는 전진한다
      - [x] 전진하면 자동차가 움직인 거리가 +1 증가한다
      - [x] 거리는 0에서 부터 시작되며 Long 타입으로 설정한다
      - [x] 거리가 음수가 될 수 없다
    - [x] 자동차는 멈춘다
      - [x] 멈춘 경우 움직인 거리는 변화하지 않는다

- [ ] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
  - [ ] 자동차는 이름을 가진다
    - [x] 이름은 5자 이하만이 가능하다
      - ex. sunli - 정상
      - ex. sunling - 예외
  - 자동차 출력시 자동차 이름을 같이 출력한다
  
- [ ] 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
  - 자동차 이름은 쉼표를 기준으로 구분한다
    - **추가** 이름 내 공백이 존재하는 경우 이름 내부에 공백이 존재하는 것으로 간주한다 (공백 역시 5자 이하에 포함한다)
    - [ ] **예외** 쉼표 없이 입력된 경우 (구분자 없이 입력된 경우) (ex.pobi woni juni)
    - [ ] **예외** 구분자가 잘못 입력된 경우 (ex. pobi#woni#juni, pobi,woni#juni)
    - [ ] **예외** 이름이 5자를 초과한 경우 (ex. pobiwo,junils)
    - [ ] **예외** 구분자 뒤에 이름이 추가로 명시되지 않은 경우 (ex.pobi,woni,)

- [ ] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
  - [ ] 이동할 횟수는 입력을 통해 받는다 
    - 수만 입력할 수 있다
    - **예외** 수 사이에 공백을 입력한 경우 예외를 발생한다 (수가 연속된 경우에만 정상적인 입력으로 간주한다)
      - ex) "      125", "12      ", "     5     " - 정상 
      - ex) "  1    56", "1  2" - 예외
    - **예외** 수가 아닌 값을 입력하면 예외를 발생한다
      - ex) "하 나", "하나", "두 번" - 예외
  
- [ ] 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
  - 무작위 값은 *pickNumberInRange()* 를 활용한다 
  - [ ] 무작위 값이 4이상이면 전진한다
  - [ ] 무작위 값이 4보다 작으면 전진할 수 없다 (=멈춘다) 

- [ ] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
  - [ ] 우승자는 한 명 이상이다

- [ ] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
  - [ ] 복수의 우승자가 발생한 경우 쉼표를 이용하여 구분한다.

- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.
  - [ ] 잘못된 값을 입력한 경우 IllegalArgumentException을 발생시킨다
    - 애플리케이션은 종료된다
